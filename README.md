# 🏡 EliteHomes App

تطبيق عقارات حديث مبني باستخدام **Flutter** يتيح للمستخدمين تصفح العقارات، إضافة للمفضلة، واستكشاف الخدمات العقارية بتصميم أنيق وتجربة استخدام سلسة.

---

## ✨ المميزات

### 🏠 الصفحة الرئيسية
- عرض العقارات المميزة
- إمكانية البحث حسب الموقع
- فلترة حسب المدن (New York, Dubai, Paris...)
- تصميم حديث وسهل الاستخدام

---

### 🏢 صفحة العقارات
- عرض جميع العقارات المتاحة
- تصميم كروت احترافي
- كل عقار يحتوي على:
  - صورة
  - السعر
  - الموقع
  - عدد الغرف والحمامات
- إمكانية الدخول لتفاصيل العقار

---

### ❤️ المفضلة
- إضافة/إزالة العقارات من المفضلة
- تحديث فوري باستخدام Provider
- شاشة مخصصة لعرض العقارات المحفوظة

---

### 📄 تفاصيل العقار
- عرض كامل لمعلومات العقار
- السعر + الموقع + التفاصيل
- وصف كامل للعقار
- تصميم قابل للتطوير وربط API

---

### 🔧 الخدمات (Services)
- أقسام متعددة:
  - Buying
  - Selling
  - Renting
  - Investing
- عرض خدمات مثل:
  - Market Analysis
  - Marketing
  - Buyer Screening
- تصميم Tabs احترافي

---

### 👤 الملف الشخصي
- عرض بيانات المستخدم
- إحصائيات النشاط (Saved - Tours - Viewed)
- تغيير اللغة
- الانتقال للإعدادات

---

### ⚙️ الإعدادات
- تغيير اللغة
- إعدادات عامة
- قابل للتطوير (Dark Mode - Notifications)

---

## 🧰 التقنيات المستخدمة

- Flutter
- Dart
- Provider (State Management)
- Material UI
